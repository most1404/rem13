# یادآور شمسی

برنامهٔ اندروید یادآور با تقویم شمسی، چک‌لیست زیرمجموعه، گروه رنگی، زنگ و اعلان با به‌تعویق‌انداختن، ساخت یادآور از جملهٔ فارسی (نوشتن یا میکروفون) و ویجت صفحهٔ اصلی.

## ساخت APK با GitHub Actions

1. یک مخزن جدید در GitHub بسازید (بدون README).
2. **همهٔ محتوای این پوشه** (نه خود پوشه یا zip) را در ریشهٔ مخزن آپلود کنید: `app`، `gradle`، `.github`، `gradlew`، `build.gradle.kts`، `settings.gradle.kts` و بقیه.
3. اگر پوشهٔ `.github` آپلود نشد: **Add file ← Create new file** و نام را بنویسید `.github/workflows/apk.yml` و محتوای فایل همین نام را از این پروژه بچسبانید.
4. تب **Actions** ← **Build APK** ← **Run workflow** (یا با هر commit خودکار اجرا می‌شود).
5. بعد از ✅ سبز، از پایین صفحهٔ اجرا، بخش **Artifacts**، فایل `yadavar-shamsi-apk` را دانلود کنید. داخل zip فایل `app-debug.apk` است.

## ساخت APK با Android Studio

1. نسخهٔ **Android Studio Ladybug (2024.2.1) یا جدیدتر** لازم است. اگر قدیمی‌تر است، اول آپدیتش کنید.
2. zip را Extract کنید. پوشهٔ `YadavarShamsi` ساخته می‌شود.
3. Android Studio ← **Open** ← همین پوشهٔ `YadavarShamsi` را انتخاب کنید (پوشهٔ داخلی `app` را نه).
4. اگر پرسید «Trust project» را بزنید. صبر کنید پایین صفحه Gradle Sync تمام شود (بار اول چند دقیقه طول می‌کشد و اینترنت لازم است؛ Studio خودش SDK و Gradle را دانلود می‌کند).
5. اگر خطای JDK داد: **File ← Settings ← Build, Execution, Deployment ← Build Tools ← Gradle ← Gradle JDK** را روی **jbr-17** یا **Embedded JDK** بگذارید.
6. از منوی بالا: **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
7. بعد از پایان، بالای صفحه پیامی با دکمهٔ **locate** می‌آید. فایل اینجاست:
   `app/build/outputs/apk/debug/app-debug.apk`
8. فایل را به گوشی بفرستید و نصب کنید (نصب از منبع ناشناس را برای برنامهٔ فایل‌ها یا مرورگر روشن کنید).

## بعد از نصب

- دکمهٔ + برای یادآور جدید. جملهٔ فارسی مثل «فردا ساعت ۷ صبح یادآوری کن قرص» را بنویسید و «بساز» را بزنید (یا میکروفون).
- در تنظیمات «اجازهٔ زنگ دقیق» و اعلان را روشن کنید.
- ویجت: روی صفحهٔ اصلی گوشی انگشت را نگه دارید ← ویجت‌ها ← یادآور شمسی. تیک عنوان یادآور را تمام می‌کند و فلش ▼ زیرمجموعه‌ها را باز می‌کند. اندازهٔ نوشته از تب تنظیمات عوض می‌شود.

نسخهٔ debug برای استفادهٔ شخصی است.

## اگر برنامه با خطا بسته شد

نسخه‌ی جدید گزارش خطا را ذخیره می‌کند و بار بعد که برنامه را باز کنید، صفحه‌ای با متن خطا نشان می‌دهد. از آن صفحه عکس بگیرید و بفرستید. دکمهٔ «پاک کردن و ادامه» برنامه را دوباره باز می‌کند.

## تغییرات نسخهٔ ۱.۰.۱

**نصب و فنی**
- `versionName = 1.0.1`؛ `versionCode` همچنان با هر ساخت بالاتر می‌رود و امضا همان `app/yadavar.jks` است، پس روی نسخهٔ قبلی (ساخته‌شده با همین کلید) بدون حذف نصب می‌شود.
- Manifest: `targetSdk 35` حفظ شد؛ فقط دو مجوز عادی `INTERNET` و `ACCESS_NETWORK_STATE` برای Drive و تشخیص آنلاین/آفلاین بودن اضافه شد؛ `usesCleartextTraffic=false`.
- دیتابیس Room به نسخهٔ ۳ رفت (ستون `earlyMinutes`، مقدار پیش‌فرض ۰) با `MIGRATION_2_3`؛ یادآورهای قبلی دست‌نخورده می‌مانند.

**پشتیبان‌گیری روی Google Drive** (علاوه بر فایل محلی؛ هیچ‌چیز حذف نشد)
- تنظیمات ← «پشتیبان‌گیری در Google Drive» ← «ورود با حساب گوگل». بعد از ورود، چند ثانیه بعد از هر تغییر، فایل `yadavar-backup.json` در پوشهٔ «یادآور شمسی» در Drive کاربر ذخیره می‌شود. هنگام ورود، اگر پشتیبانی در Drive باشد خودکار با یادآورهای برنامه ادغام می‌شود (نسخهٔ جدیدتر برنده است).
- دسترسی فقط `drive.file` است (برنامه فقط فایل‌های خودش را می‌بیند).
- **راه‌اندازی یک‌باره (بدون آن ورود کار نمی‌کند):** در Google Cloud Console یک پروژه بسازید ← Google Drive API را Enable کنید ← OAuth consent screen را تنظیم کنید (scope: `.../auth/drive.file`؛ تا زمان انتشار، حساب خودتان را در Test users اضافه کنید) ← Credentials ← Create OAuth client ID ← نوع **Android** ← Package name: `app.yadavar.shamsi` و SHA-1 کلید `yadavar.jks`:
  `4B:73:6C:DE:99:01:DC:68:8B:A7:23:A6:BD:80:2C:E8:41:51:3E:E6`
  (کد دیگری لازم نیست؛ Client ID در کد نیست و گوگل با نام بسته و SHA-1 برنامه را می‌شناسد.)
- نیاز: گوشی با Google Play Services و اینترنت.

**ویجت**
- متن یادآورهای گذشته قرمز، امروز سبز، فردا به بعد رنگ عادی تم ویجت. بین تاریخ و ساعت `-` است. دکمهٔ `+` بعد از ساعت است. گوشه‌ها گردتر (۲۸dp). تاریخ شمسی روز دست‌نخورده ماند. ساعت ویجت با رنگ تم ویجت هماهنگ است.
- ۱۵ پس‌زمینهٔ ویجت (۵ تیره) به‌جای ۷ تا، هرکدام با رنگ اصلی خودش.

**اعلان آلارم**
- دکمه‌های اعلان: «انجام شد»، «۱۰ دقیقه»، «بستن» (دکمه‌های اصلی) و در حالت باز‌شدهٔ اعلان: «۱۵ دقیقه»، «۳۰ دقیقه»، «۱ ساعت»، «زمان دیگر». اندروید بیش از ۳ دکمهٔ Action نشان نمی‌دهد؛ به همین دلیل ۴ دکمهٔ دیگر داخل نمای گسترده‌اند. همه با `PendingIntent` و `AlarmReceiver` کار می‌کنند و «زمان دیگر» صفحهٔ انتخاب تاریخ و ساعت را باز می‌کند.

**ظاهر و رفتار**
- انیمیشن تیک یادآور (پر شدن دایره، ضربهٔ کوچک، ناپدید شدن نرم)، ورود نرم یادآور تازه، محو شدن بین تب‌ها و صفحهٔ ویرایش.
- عنوان «یادآور شمسی» از صفحهٔ اصلی برداشته شد؛ فقط تاریخ شمسی مانده.
- ۱۳ رنگ برنامه؛ کنار هر نام رنگ (برنامه و ویجت) یک دایره هم‌رنگ.
- فاصله‌ها و تایپوگرافی (ارتفاع خط بیشتر) استانداردتر؛ تنظیم «اندازهٔ نوشته‌های برنامه» (کوچک تا خیلی بزرگ) جدا از اندازهٔ ویجت.
- جستجو در عنوان، موارد، تاریخ (حروف و عدد، فارسی/لاتین)، ساعت و تکرار؛ همهٔ کلمات باید پیدا شوند.
- دکمه‌های شناور مدرن: «+» و میکروفون. با اینترنت، تشخیص گفتار آنلاین سیستم؛ بدون اینترنت، همان تشخیص‌دهندهٔ سیستم با `EXTRA_PREFER_OFFLINE` (نیازمند بستهٔ فارسی آفلاین دانلودشده در تنظیمات صدای گوگل یا برنامهٔ تشخیص گفتار آفلاین).
- دکمهٔ «ذخیره» با رنگ اصلی تم.
- پایین تنظیمات: «برنامه نویسان: محمد یگانه - مصطفی ابراهیمی» و زیرش «ورژن ۱.۰.۱» (وسط‌چین).
- **یادآوری زودتر:** وقتی ساعت تنظیم شده باشد: سر وقت (پیش‌فرض)، ۱۵ دقیقه قبل، ۳۰ دقیقه قبل، ۱ ساعت قبل، زمان دیگر (دقیقهٔ دلخواه). مقدار در `earlyMinutes` ذخیره و در زمان‌بندی آلارم اعمال می‌شود.

## تغییرات نسخهٔ ۷

- **به‌روزرسانی بدون حذف:** پروژه حالا با یک کلید امضای ثابت (`app/yadavar.jks`) ساخته می‌شود و هر ساخت versionCode بالاتری دارد. قبلاً هر ساخت در GitHub با کلید تازه‌ای امضا می‌شد و به همین دلیل نصب روی نسخهٔ قبل خطا می‌داد. **فقط یک بار** باید نسخهٔ قدیمی (که با کلید دیگری امضا شده) را حذف کنید؛ از آن به بعد هر نسخه روی قبلی نصب می‌شود. APK نهایی از نوع release است (`app-release.apk`).
- **پشتیبان‌گیری خودکار:** در تنظیمات یک فایل پشتیبان انتخاب می‌شود؛ چند ثانیه بعد از هر تغییر همهٔ یادآورها (از جمله انجام‌شده‌ها) خودکار در آن ذخیره می‌شوند. فایل بیرون از برنامه است و با حذف برنامه نمی‌ماند. بازیابی هم از همان صفحه ممکن است. علاوه بر آن، پشتیبان‌گیری خودکار خود اندروید (حساب گوگل) برای دیتابیس فعال است.
- **ویجت:** تاریخ شمسی همیشه نمایش داده می‌شود (ساعت دیگر کل عرض ردیف را نمی‌گیرد). گوشه‌ها گردتر شد.
- **صفحهٔ یادآور جدید:** کادر مکان و کلید «هشدار سر وقت» حذف شد (هشدار همیشه فعال است). دکمهٔ «ذخیره» با رنگ اصلی برنامه (بنفش) هماهنگ است.
- **ظاهر:** گوشه‌های گرد در کل برنامه؛ کارت‌های یادآور با سایهٔ ملایم؛ فاصلهٔ بیشتر در تنظیمات؛ دکمهٔ شناور «+» با میکروفون در گوشهٔ پایین؛ تاریخ‌های گذشته قرمز ملایم و امروز سبز؛ نوار جستجو بالای صفحهٔ اصلی.
- **تنظیمات:** نام برنامه‌نویسان از صفحهٔ اصلی به پایین‌ترین بخش تنظیمات منتقل شد (وسط‌چین) و زیر آن «ورژن ۱.۰.۰» آمده است.

## تغییرات نسخهٔ ۶

- **ویجت:** بین یادآورهای دو تاریخ مختلف یک خط نازک جداکننده کشیده می‌شود.
- **آلارم:** دکمه‌های صفحه: «انجام شد»، «تعویق»، «بستن». با «تعویق» گزینه‌های ۵ دقیقه، ۱۵ دقیقه، ۳۰ دقیقه، ۱ ساعت و «زمان دیگر» (تاریخ و ساعت دلخواه) نمایش داده می‌شود. در اعلان هم دکمهٔ «تعویق» صفحهٔ آلارم را با همین گزینه‌ها باز می‌کند.
- **صفحهٔ اصلی:** زیر «یادآور شمسی» نام برنامه‌نویسان نوشته شده است.
- **تنظیمات:** بین بخش‌ها خط جداکننده گذاشته شد.

## تغییرات نسخهٔ ۵

- **ویجت:** فقط دکمهٔ فیلتر فعال رنگی است (هر دکمه همیشه رنگ خودش را صریح می‌گیرد، پس رنگ حالت قبلی نمی‌ماند). تاریخ شمسی سمت راست کنار «+» و ساعت زندهٔ همان لحظه سمت چپ است (جهت چیدمان خودکار با زبان گوشی تنظیم می‌شود). تاریخ هم‌چنین بعد از نیمه‌شب خودکار تازه می‌شود.
- **لیست ویجت:** کنار ساعت، روز و ماهِ یادآور هم نوشته می‌شود.
- **تعامل در ویجت:** لمس متن یادآور، برنامه را مستقیم روی صفحهٔ ویرایش همان یادآور باز می‌کند. لمس دایرهٔ کنار آن، یادآور را تمام می‌کند. در زیرمجموعه‌ها هم دایره مورد را تیک می‌زند.
- **تنظیمات:** «رنگ پس‌زمینهٔ ویجت» (بنفش روشن، سفید، نعنایی، آبی روشن، هلویی، صورتی، تیره). روی پس‌زمینهٔ تیره رنگ نوشته‌ها خودکار روشن می‌شود.
- **صفحهٔ آلارم:** عنوان دیگر زیر آیکون‌های نوار وضعیت نمی‌رود. «۱۵ دقیقه» از همه‌جا (صفحه و اعلان) حذف شد. گزینه‌های به تعویق: ۵ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۲ ساعت و «در زمان دیگر» (انتخاب تاریخ شمسی و ساعت دلخواه؛ زمان گذشته پذیرفته نمی‌شود). در اعلان، دکمهٔ «۵ دقیقه» جای «۱۵ دقیقه» را گرفت.

## تغییرات نسخهٔ ۴

- **صدای هشدار:** از «تنظیمات ← صدای هشدار» یکی از زنگ‌های گوشی یا یک آهنگ از حافظه انتخاب می‌شود. صدا ملایم شروع می‌شود (افزایش تدریجی) و به‌طور پیش‌فرض ۱۰ ثانیه پخش می‌شود (۱۰، ۳۰ یا ۶۰ ثانیه). با «انجام شد»، «۱۵ دقیقه» یا «بستن» زودتر قطع می‌شود.
- **صفحهٔ اصلی:** کادر پیشنهادی و دکمهٔ «بساز» حذف شد. فیلترها: همه، گذشته، امروز، این هفته، این ماه (هفته از شنبه تا جمعه، ماه شمسی) و «انجام‌شده».
- **حذف شد:** ستاره‌دار کردن و بخش گروه‌ها (اطلاعات قبلی در دیتابیس سالم می‌ماند).
- **ویجت:** تاریخ شمسی (راست) و ساعت زنده (چپ) با رنگ بنفش تیره، خط جداکنندهٔ ضخیم، دکمهٔ + برای ثبت مستقیم یادآور، فیلترهای همه | گذشته | امروز | این هفته | این ماه با خط‌های عمودی نازک. فیلتر ویجت مستقل از فیلتر صفحهٔ اصلی ذخیره می‌شود و با همان منطق کار می‌کند.
- **تیک در ویجت:** ویجت حالا مستقیم از دیتابیس زنده می‌خواند و یادآور تمام‌شده بلافاصله از آن حذف می‌شود.
